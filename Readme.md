`🔌 Generator Wiązek Molex (Seria 43025)`

Interaktywna aplikacja webowa CAD do projektowania wiązek przewodowych, konfiguracji złączy Molex (w tym rzutów czołowych złączy dwurzędowych serii 43025) oraz generowania dokumentacji montażowej (Wire Run List). 

  `✨ Główne funkcje.`
  - Domyślny czysty układ startowy: Dwa niepołączone, 8-pinowe gniazda Molex 43025-0800 (J1 oraz J2) gotowe do projektowania.
  - Realistyczny rzut czołowy złączy Molex 43025:Odwzorowanie komory z kluczowaniem polaryzacyjnym (ścięcia $45^\circ$), wpustami zatrzasku terminala oraz bocznym zatrzaskiem obudowy.
  - Obsługa złączy 1-rzędowych i 2-rzędowych (od 2 do 24 pinów) z przełączaniem trybu numeracji (Standard Molex lub Naprzemiennie).
  - Uniwersalny Zapis i Eksport (Windows / macOS / Android / iOS / Linux / Obsidian):Obraz PNG (Retina), Wektor CAD (.SVG), Dokumentacja Offline (.HTML), Tabela Excel (.CSV) oraz Plik projektu          (.JSON) wraz z szybkim kopiowaniem kodu JSON prosto do notatek w Obsidianie.
