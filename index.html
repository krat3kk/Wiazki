Centrum Zapisu i Eksportu (PC / Mac / Android / iPhone)

Windows / macOS / Linux: Kliknij „Zapisz obraz PNG”, „Wektor .SVG” lub „Zapisz projekt .JSON” – przeglądarka pozwoli wybrać folder docelowy lub zapisze w Pobrane.
iPhone / iPad (iOS): Dotknij „Udostępnij / Galeria”, a następnie wybierz „Zapisz obraz” (trafi do Zdjęć) lub „Zapisz w Plikach”.
Android: Kliknij „Zapisz obraz PNG” (trafi bezpośrednio do Pobranych/Galerii) lub „Udostępnij”, aby wysłać na Dysk Google / WhatsApp / e-mail.
